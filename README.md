# Login Form

A clean, responsive login form built with HTML, CSS and a bit of JavaScript.

## Description

This repository contains a simple, modern login form UI designed as a small frontend project — perfect for practice or to drop into a landing page. It focuses on layout, form styling, and subtle interactions.

## Preview

![Login form preview](./Screenshot%202024-08-10%20233008.png)

## Features

- Responsive layout
- Modern, minimal styling using CSS
- Client-side form markup and basic JS handling

## Files

- `index.html` — the HTML page containing the login form
- `style.css` — styles for the form and layout
- `Screenshot 2024-08-10 233008.png` — project preview image
- `beautiful-mountains-landscape (3).jpg` — background/reference image used in the project

## How to run

1. Clone this repository:

   git clone https://github.com/BinaryVortex/Login-Form-107.git

2. Open `index.html` in your browser (double-click or use `Live Server` in VS Code).

That's it — no build tools or dependencies required.

## Customize

- Edit `style.css` to change colors, spacing, or typography.
- Replace the background image `beautiful-mountains-landscape (3).jpg` with your own asset.
